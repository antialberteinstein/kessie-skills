# Mẫu issue

Tiêu đề có tiền tố: `[Feature]`, `[Bug]`, `[Verify]`, `[Chore]`. Không đưa secret hay dữ liệu cá nhân vào issue.

## Feature
```markdown
## Mục tiêu
## Đặc tả
- RequirementsOutline §… · docs/modules/<Module>.md AC-…
## Tiêu chí nghiệm thu
| Mã | Tình huống | Kết quả |
## Phạm vi kỹ thuật
- [ ] Dữ liệu + phân quyền + test (/kessie-skills:proj build › backend)
- [ ] Logic + unit test
- [ ] UI + E2E (/kessie-skills:proj build › frontend)
- [ ] CHANGELOG [Unreleased]
## Ngoài phạm vi
## Cần môi trường thật để xác minh
```

## Bug
```markdown
## Hiện tượng / mong đợi
## Tái hiện
## Môi trường (thiết bị/trình duyệt, OS, phiên bản app, bản cài)
## Mã hỗ trợ / log đã che
## Giả thuyết (ghi rõ là giả thuyết)
## Điều kiện đóng (kiểm chứng nào đủ để dùng Closes)
```

## Verify
```markdown
## Cần xác minh
## Bằng chứng hiện có và vì sao chưa đủ
## Checklist
## Kết quả (thiết bị/môi trường, ngày, đạt/không, ảnh đã che)
```

## Chore
```markdown
## Việc · Lý do · Lệnh kiểm chứng
```
