## Thay đổi

Mô tả vấn đề, hành vi sau thay đổi và issue liên quan (`Closes #N` chỉ khi đã xác minh; nếu chưa: `Refs #N`).

## Kiểm chứng

Ghi các lệnh kiểm tra đã chạy và kết quả; với giao diện, thêm ảnh đã che dữ liệu riêng tư.

- [ ] Typecheck, lint và format đạt.
- [ ] Unit/integration và E2E liên quan đạt, hoặc giải thích vì sao không áp dụng.
- [ ] Không đưa credentials hoặc dữ liệu cá nhân vào code, log và ảnh.
- [ ] Nếu có thay đổi dữ liệu: migration, phân quyền và cách triển khai đã được kiểm tra.

## Triển khai và giới hạn

Ghi thay đổi cấu hình, migration cần áp dụng, ảnh hưởng tương thích, cần build lại hay không, và phần chưa kiểm tra trên môi trường/thiết bị thật.
